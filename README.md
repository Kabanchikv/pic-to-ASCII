# 🎨 Конвертер картинок в цветной ASCII и Пиксель-Арт (CMD + PNG)

Простая и быстрая консольная программа на Python, которая превращает любые фотографии, мемы и картинки в цветной символьный арт прямо в командной строке Windows или сохраняет результат в высоком разрешении в формате `.png`.

## ✨ Возможности
* **Настоящий цвет (TrueColor):** Поддержка 24-битной палитры прямо в стандартной консоли Windows.
* **Автоконтраст и резкость:** Автоматическое улучшение деталей, чтобы даже сложные цветные фото выглядели четко.
* **Умное сохранение пропорций:** Автоматическое определение формата (`16:9`, `4:3`, `1:1` и др.) и сжатие без искажений.
* **Квадратные пиксели:** Режимы отрисовки двойными символами (`@@`) и сплошными блоками (`██`), чтобы картинка не растягивалась по вертикали.
* **Экспорт в PNG:** Сохранение готового ASCII-арта в полноценную картинку высокого разрешения с автоматическим открытием файла.

## 🚀 Как скачать и запустить (без установки Python)

1. Перейдите в раздел **[Releases (Релизы)](../../releases)** (справа на странице репозитория).
2. В последнем релизе скачайте файл **`ascii_converter.exe`** (в блоке *Assets*).
3. Запустите скачанный файл двойным кликом.

> **⚠️ Примечание для Windows 10/11:** 
> При первом запуске фильтр SmartScreen может показать синее окно *«Система Windows защитила ваш компьютер»* (так как у программы нет платной цифровой подписи разработчика). Нажмите **«Подробнее»** ➔ **«Выполнить в любом случае»**.

## 🎮 Как пользоваться программой

1. Откройте программу и **просто перетащите мышкой любую картинку** из проводника прямо в черное окно консоли.
2. Нажмите `Enter` и выберите один из **7 режимов работы**:
   * `1` — **Стандартный в консоль:** сжатие под ширину окна (120 символов).
   * `2` — **1 символ = 1 пиксель:** оригинальное разрешение в консоль (вытянутое по вертикали).
   * `3` — **Оригинальная ширина:** с коррекцией высоты под консольный шрифт.
   * `4` — **Пиксель-арт в консоль (`██`):** квадратные пиксели из сплошных блоков.
   * `5` — **ASCII-арт в консоль (`@@`):** квадратные пиксели из двойных букв.
   * `6` — **Сохранить в PNG (Буквы):** рендер цветного ASCII-арта в файл `.png` (сохраняется рядом с оригиналом).
   * `7` — **Сохранить в PNG (Блоки):** рендер блочного пиксель-арта в файл `.png`.
3. Для выхода из программы введите `q` или `выход`.

💡 *Совет: Если вы выводите большую картинку прямо в консоль (режимы 2–5), зажмите `Ctrl` и покрутите колесико мыши вниз, чтобы уменьшить шрифт терминала — тогда картинка поместится на экран целиком!*

## 🛠 Запуск из исходного кода (для разработчиков)

Если вы хотите запустить скрипт через Python (`3.10+`):

1. Установите библиотеку Pillow:
   ```bash
   pip install pillow
   ```
2. Запустите скрипт:
   ```bash
   python ascii_converter.py
   ```
